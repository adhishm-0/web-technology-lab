EXPERIMENT 05
JavaScript DOM Elements and Events

This is a simple beginner-level lab page. The Experiment 4 files were not
edited.

Files:
- index.html: StarVerse page with the experiment activities
- style.css: basic page styling
- script.js: DOM selection, event listeners, calculations, and random results
- apple.svg, orange.svg: fruit images used in the garden
- heads.svg, tails.svg: coin faces used by the flip activity

Activities demonstrated:
1. DOM updates using an element ID and click, keyup, and document click events
2. Finding the shortest and longest word in a sentence
3. BMI calculation and body-type classification
4. A randomly planted apple and orange garden
5. Rupee/dollar conversion using the rates in the handout
6. A coin flip with heads and tails totals
7. Cake order cost with 9% tax and the selected 10%, 15%, or 20% tip

To open the experiment, open index.html in a modern web browser. No server or
external libraries are required.
