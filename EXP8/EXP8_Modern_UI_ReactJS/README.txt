Experiment 8: Modern User Interface Design using ReactJS

Run locally:
1. Install Node.js.
2. In this folder run: npm install
3. Start the app with: npm run dev

The app contains:
- User registration with required-field, name, email, password, age, mobile, gender, and state validation.
- Home, About, and Contact routes with React Router navigation.
- Reusable Navbar, RegistrationForm, and Footer components.
- A responsive login page.
- A student details page that updates live using React state.

For the captured demo screens, use /register?demo=1 and /login?demo=1.

Report files:
- EXP8_Modern_UI_ReactJS.pdf — formatted experiment record with program code and output screenshots for Questions 1–5.
- EXP8_Modern_UI_ReactJS.docx — editable Word version with page border and matching header/footer.
- output_screenshots/ — browser captures for each question.

The demo query string preloads sample values and shows the successful registration/login states.
