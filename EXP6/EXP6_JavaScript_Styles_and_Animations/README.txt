Experiment 6: JavaScript Styles and Animations

Run the program:
1. Open index.html in a modern browser.
2. Use the page controls to try each of the five questions.
3. The background changes automatically every 30 seconds; use Change Color Now to preview it immediately.

Files:
- index.html: all five program demonstrations
- style.css: page layout and styles
- script.js: JavaScript solution code for all five questions
- output_screenshots/: captured browser output for each question

To show one question by itself, open index.html?q=1 through index.html?q=5.
