Experiment 7: Working with jQuery

Run the application:
1. Open index.html in a browser with internet access. The page loads jQuery 3.6.0 from Google Hosted Libraries.
2. Use the Budget Calculator, Cake Order Calculator, and Car Body Workshop panels.
3. The budget percentage values must add up to 100%; invalid values trigger an alert.

Question details:
- Budget values are divided according to the four percentages.
- Cake costs use ₹100/₹200/₹400 for small/medium/large cakes, 9% tax, and a selectable tip.
- The car workshop demonstrates paint color, wheel finish, window tint, and spoiler controls.

Files:
- index.html: all three question interfaces
- style.css: page design and responsive layout
- script.js: jQuery actions and calculations
- output_screenshots/: browser captures for each question

Capture one question alone with index.html?q=1, ?q=2, or ?q=3.
